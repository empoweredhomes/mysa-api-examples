# Security

## Reporting a vulnerability

Report vulnerabilities in these examples, or in the Mysa Consumer API,
privately through this repository's
[**Report a vulnerability**](https://github.com/empoweredhomes/mysa-api-examples/security/advisories/new)
form (the **Security** tab). Do not open a public issue or pull request for a
vulnerability. Test only against your own Mysa account and devices.

## Never share credentials

- Do not paste access tokens, refresh tokens, authorization codes or Mysa
  passwords into logs, screenshots, issues or anything public.
- The API uses public PKCE clients, so there is no client secret. If you find
  a client secret or a token in this repository, report it as above.
